# JustiFica

Prototipo escolar de solicitud y entrega de justificantes de inasistencia (datos simulados).

- Páginas: este repositorio, publicado con GitHub Pages.
- Backend: Google Apps Script (`backend/Code.gs`): base de datos en una hoja de cálculo privada, comprobantes en Google Drive y avisos por Gmail.

Páginas: `index.html` (alumno), `justificante.html`, `verificar.html` (docentes), `jefatura.html`, `eventos.html`.
